## 3. 問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
在 Python 中，加上引號的 `"4"` 是**字串（`str`）**型別，電腦只會把它當作一般的文字符號，而不是具有數學意義的數值。因為字串不支援除法運算（`total_amount / "4"` 會直接產生 `TypeError` 錯誤），所以必須先用 `int()` 轉換成**整數（`int`）**，才能進行平均分攤的數學計算。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
- **改變順序後的計算過程**：
  1. 先扣折價券：$1200 - 100 = 1100$ 元
  2. 再算 10% 服務費：$1100 \times 0.10 = 110$ 元
  3. 應付總額：$1100 + 110 = 1210$ 元
- **結果不同的原因**：
  因為乘法對減法具有分配律，折價券的 100 元在「先扣折價券」的情況下，少被計算了 $10\%$ 的服務費（$100 \times 0.10 = 10$ 元）。因此總金額會從原本的 $1220$ 元變成 $1210$ 元，相差了 $10$ 元。
